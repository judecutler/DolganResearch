# annotations/

Hand annotations by Jude and Dustan. Small CSV files only.

Naming: `<study>_<round>_<annotator>.csv`, for example `evid_pilot_dustan.csv`.

Rules:
- Never change the ID columns (`item_id`, `token_id`). They are how annotations merge back into the data.
- One file per annotator per round. Do not edit each other's files. Disagreements are resolved in a separate `..._adjudicated.csv`.
- Allowed values for each coding column come from the codebook in the study folder. A merge script will reject values outside the list.
- Annotation sheets are generated by code (see `docs/DATA_PREP_PLAN.md`, stage 7). Do not build them by hand.
